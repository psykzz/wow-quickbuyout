# CurseForge listing

## Summary

One-click Auction House buyouts for gear: no confirmation popup, buys the selected armor or weapon auction, with the cheapest selected by default.

## Description

**Quick Buyout** removes the confirmation popup from the Auction House for gear. Click **Buyout** and the selected armor or weapon auction is bought instantly, TradeSkillMaster-style. The cheapest auction is selected for you, so most of the time it's just one click.

### Features

- **No confirmation popup** for armor and weapon buyouts
- **Buys what you selected** - pick any auction in the list and Buyout purchases exactly that one
- **Cheapest selected by default** - when you open an item group, the cheapest buyable auction is selected, skipping your own auctions and bid-only listings
- **Click repeatedly** - after each purchase the selection resets to the next cheapest auction
- **Double-purchase protection** - extra clicks are ignored while a purchase is in progress, and auctions you already bought are never retried
- **Nothing else changes** - commodities, other item types, bids, and Blizzard's unique-crafted-item warning still ask for confirmation
- **Zero configuration** - no settings, no slash commands, just install and go

### How to use

1. Open the Auction House and search for an armor or weapon item.
2. Click the item group to see its auctions. The cheapest is already selected; click another row if you want that one instead.
3. Click **Buyout**. Done.

### Compatibility

Works with the modern Auction House UI used by:

- Retail
- Mists of Pandaria Classic
- Classic Era / Anniversary clients with the new Auction House UI

Clients that use the legacy Auction House UI are not supported.

### Warning

Purchases happen **immediately** with no confirmation. Check which auction is selected and the price shown next to the Buyout button before clicking.
